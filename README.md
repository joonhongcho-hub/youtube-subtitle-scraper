# 유튜브 채널 자막 일괄 수집 도구

유튜브 채널 URL(또는 채널명)을 입력하면 해당 채널의 모든 영상 자막을 수집해
정제된 텍스트 파일로 저장하고, 전체 목록을 엑셀 인덱스로 정리합니다.
**CLI와 웹 UI 두 가지로 쓸 수 있습니다.**

영상 수백 개를 한 번에 돌리는 작업이라 중단·차단·저장 실패가 잦습니다.
그래서 단순 수집보다 **중단 후 재개**와 **실패 분류·재시도**에 무게를 두고 만들었습니다.

## 설치

파이썬 3.10 이상이 필요합니다.

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## 웹 UI

```bash
python -m uvicorn server:app --port 8765
```

브라우저에서 `http://127.0.0.1:8765` 를 엽니다.
서버도 자막도 모두 내 컴퓨터 안에 있고, 유튜브에서 자막을 받아올 때만 외부와 통신합니다.

```
1 채널 입력 → 2 수집 범위 → 3 실행 → 4 다운로드
```

- **채널 입력** — 채널명을 치면 후보가 드롭다운으로 뜹니다 (방향키·Enter로 선택).
  URL을 붙여넣으면 곧장 확정됩니다.
- **수집 범위** — 일반 영상·쇼츠·라이브의 개수와 예상 소요 시간을 먼저 보여줍니다.
  날짜·길이 필터, 정렬(조회수·업로드일), 상위 N개 제한, 타임스탬프 유지를 고를 수 있습니다.
- **실행** — 진행률과 실시간 로그가 흐릅니다. 중지해도 그때까지 받은 자막은 남습니다.
- **다운로드** — 전체 ZIP · `index.xlsx` · 하나로 병합한 텍스트 중에 고릅니다.
  영상을 클릭하면 자막을 미리 볼 수 있습니다.

### 작업을 잃지 않습니다

브라우저를 새로고침하거나 서버를 재시작해도 작업이 사라지지 않습니다.
진행 상황은 `output/_jobs/`에 저장되고, 다시 접속하면 상단에 배너가 떠서
**이어보기**나 **이어서 실행**을 고를 수 있습니다. 이어서 실행하면 이미 받은 영상은
건너뛰고 멈춘 지점부터 계속합니다.

## CLI

```bash
python main.py <채널URL 또는 채널명> [옵션]
```

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--limit N` | 앞에서부터 N개만 처리 (테스트용) | 전체 |
| `--output DIR` | 출력 폴더 | `./output` |
| `--lang ko,en` | 자막 언어 우선순위 | `ko,en` |
| `--timestamps` | `[00:12] 문장` 형태로 시각을 남김 | 꺼짐 |

```bash
# 채널명으로 검색해 번호로 선택
python main.py "조코딩"

# URL 직접 지정, 5개만 테스트
python main.py "https://www.youtube.com/@jocoding" --limit 5

# 쇼츠 탭
python main.py "https://www.youtube.com/@jocoding/shorts" --output ./output-shorts

# 업로드 전체 (영상+쇼츠+라이브) — 채널 ID의 UC를 UU로 바꾼 플레이리스트
python main.py "https://www.youtube.com/playlist?list=UUQNE2JmbasNYbjGAcuBiRRg"
```

## 출력 구조

```
output/
  videos.json          채널 영상 목록 (있으면 무조건 재사용)
  processed_ids.json   처리 완료 기록
  failed_videos.json   실패 기록 + 사유
  index.xlsx           영상 제목 | 업로드일 | 파일경로 | 원본 URL | 상태
  {채널명}/{업로드일}_{영상제목}.txt
```

## 동작 방식

1. **채널 식별** — URL이면 그대로, 채널명이면 검색 후 번호 선택 (동명 채널 구분)
2. **영상 목록 수집** — `yt-dlp --flat-playlist`. `videos.json`이 있으면 재사용하므로,
   새 영상을 반영하려면 이 파일을 직접 삭제해야 합니다.
3. **자막 수집** — `youtube-transcript-api`가 기본 경로, 실패하면 `yt-dlp`로 폴백.
   수동 자막 → 자동생성 자막 순으로 찾고, 언어는 `--lang` 순서를 따릅니다.
4. **정제** — 타임스탬프·인라인 태그·메타데이터 제거, 자동자막 중복줄 병합, 문단 재구성
5. **저장** — 영상 1개마다 즉시 저장

## 안전장치

**라이브러리 사전 검증** — 본 작업 전 `youtube-transcript-api`를 영상 1개로 테스트합니다.
실패하면 yt-dlp 단독 경로로 자동 전환하고 알려줍니다.

**파일명 정제** — `/ \ : * ? " < > |` 치환, 이모지·제어문자 제거, 100자 상한,
중복 시 `_1`, `_2` 부여.

**증분 저장 / 재개** — 영상 1개를 처리할 때마다 즉시 디스크에 반영합니다.
중간에 끊겨도 다시 실행하면 이미 처리한 영상은 `Skipping:` 로그를 남기고 건너뜁니다.

**차단 방지** — 요청 사이 3~8초 랜덤 대기, 429 등 차단 시 1초 → 2초 → 4초 backoff,
일반 브라우저 User-Agent 지정. `curl-cffi`가 설치돼 있으면 yt-dlp가 Chrome으로 위장해
차단 확률이 크게 낮아집니다.

브라우저 쿠키(`--cookies-from-browser`)는 사용하지 않습니다.

## 자막 정제

자동생성 자막은 한 단어씩 누적되며 같은 문장이 여러 줄 반복됩니다.

```
안녕하세요 여러분
안녕하세요
안녕하세요 여러분
오늘은 미국
안녕하세요 여러분 오늘은 미국 본사에
```

새 줄이 직전 줄들이 합쳐진 형태인지 최대 4줄까지 거슬러 비교해 하나로 합칩니다.
짧은 줄(8자 미만)은 "이제", "음" 같은 실제 발화일 수 있어 병합하지 않습니다.

실측 기준 6,456줄 원본 VTT가 803줄로 줄어듭니다.

## 실패 분류

| 사유 | 의미 | 재시도 |
|---|---|---|
| `NO_SUBTITLES` | 자막이 아예 없음 | 불가 |
| `PRIVATE_VIDEO` | 비공개·삭제·멤버십 전용 | 불가 |
| `FETCH_FAILED` | 요청 실패 | 가능 |
| `RATE_LIMITED` | 차단 | 가능 |
| `TIMEOUT` | 시간 초과 | 가능 |

실행이 끝나면 리포트를 출력하고, 재시도 가능한 실패가 있으면 다시 시도할지 묻습니다.
재시도할 때는 대기 시간을 2.5배로 늘리며, 무한 반복을 막기 위해 최대 3회로 제한합니다.

```
==============================================
성공: 605개
실패: 120개
  - PRIVATE_VIDEO: 120개 (재시도 불가)
==============================================
```

## 코드 구조

| 파일 | 역할 |
|---|---|
| `main.py` | CLI |
| `engine.py` | 수집 엔진 (CLI·웹이 함께 씀) |
| `server.py` | 웹 API + WebSocket |
| `jobs.py` | 작업 상태 저장·복구 |
| `static/` | 웹 화면 (HTML + JS) |
| `channel.py` | 채널 식별 + 영상 목록 수집 |
| `subtitle.py` | 자막 수집 (transcript-api + yt-dlp 폴백) + 사전 검증 |
| `cleaner.py` | 자막 정제 |
| `storage.py` | 파일 저장 + 파일명 정제 + index.xlsx |
| `report.py` | 결과 리포트 + 재시도 처리 |

## 참고

수집한 자막은 해당 채널 제작자의 저작물입니다. 개인적인 학습·분석 용도로만 사용하고,
재배포하지 마세요. 이 저장소도 `output/`을 `.gitignore`에 넣어 제외합니다.
